# Responsabilidades por designar

| Función | Responsabilidad propuesta | Persona/aceptación |
|---|---|---|
| Institución | Autorizar alcance/participantes/procesos/decisión final | Pendiente |
| Coordinación pedagógica | Contenido por grado, criterios/feedback/evidencias, valoración humana | Pendiente |
| Desarrollo/QA | Código, pruebas, defectos, trazabilidad y candidatos | Pendiente |
| Infraestructura | Secretos/roles/TLS/build/observabilidad/backup/DR | Pendiente |
| Seguridad/privacidad/legal | Riesgos, tratamiento de menores, derechos/encargados/incidentes/retención | Pendiente |
| Soporte | Canal, intake, escalamiento y continuidad | Pendiente |
| Custodio de respaldo | Claves/copias separadas y restore drills autorizados | Pendiente |

No nombres/firma/contratos inventados. Un Administrador de aplicación no obtiene por defecto autoridad cloud/legal o acceso a conversaciones/secretos. Separar ejecución de revisión cuando sea posible; no auditoría independiente certificada en esta intervención.
