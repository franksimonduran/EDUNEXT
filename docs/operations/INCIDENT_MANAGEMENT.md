# Gestión de incidencias

Registro futuro: ID, fecha, categoría, descripción minimizada, severidad, alcance, responsable por designar, contención, causa, cambio, prueba/regresión y aprobación de cierre. No hechos/resoluciones ficticios.

Flujo: recibir → clasificar → contener con preservación de datos → escalar → reproducir en sintético → corregir mínimo → verificar específica/regresión → documentar → decidir reapertura. Cuenta comprometida/datos expuestos: privacidad/seguridad; error de nota: coordinación académica y trazabilidad autorizada; respuesta/Sync: técnico sin sobrescritura; contenido: revisor pedagógico; caída: operador/proveedor cuando exista.

Obligaciones de comunicación/notificación requieren responsable/legal y hechos verificables, no plazos supuestos. No comunicar institucionalmente desde esta entrega. Si no existe capacidad de respuesta, NO-GO para usuarios reales.
