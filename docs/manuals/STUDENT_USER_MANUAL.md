# Manual del estudiante — prototipo, no uso escolar autorizado

## Antes de empezar

EDUNEXT busca ayudarte a aprender. Esta copia todavía no está aprobada para estudiantes reales: usa solo ejemplos ficticios con un adulto responsable autorizado para la revisión técnica. Necesita un navegador moderno; no compartas contraseña, dirección, teléfono ni datos de tu familia.

## Acceso y Dashboard

`/login.html` muestra el formulario. El login real y la recuperación de contraseña no están verificados aquí; no hay una contraseña universal. La selección de perfil demo no da permisos reales. `/student/index.html?grade=4` muestra una **demostración**; sus cifras no son tus notas. No entres a datos de otra persona.

## Qué puedes explorar y qué no está confirmado

| Sección | Orientación de esta versión |
|---|---|
| Mis cursos (`aprende.html`) | Elige grado de muestra y curso; catálogo demo, no matrícula real |
| Curso/unidad/lección | Lee texto y ejemplos; audio incluido cuando disponible. Usa controles de reproducción/pausa; puedes leer la transcripción |
| Prácticas/juegos | Lee la consigna, responde con teclado o controles. El feedback local no es nota oficial ni entrega confirmada |
| Evaluaciones | Vista de muestra; evaluación académica real completa no aceptada. No usar para una prueba escolar |
| Progreso/logros | Demo y API inicial; abrir una página no demuestra aprendizaje ni insignia confirmada |
| Tareas/agenda | Hay modos demo/API iniciales. No digas “entregada” sin confirmación real del servidor |
| Perfil | Preferencias locales no cambian tus permisos ni datos institucionales |
| Tutor | Puede estar deshabilitado o mostrar ejemplos escritos. No es tu docente; no compartas datos personales |
| Traductor/diccionario | Una entrada de vocabulario no es traducción contextual generada. Comprueba idioma y fuente |
| Pronunciación | Referencia/orientación; no evaluación del habla. No hace falta grabarte para leer o escuchar |

## Offline y Sync

El navegador puede indicar “sin conexión”, pero eso no garantiza que una actividad esté descargada. El Sync confirmado y la separación entre cuentas **no están aprobados**. Guardado local/pendiente no significa enviado. No borres almacenamiento, desinstales o cambies cuenta para arreglar una respuesta pendiente; pide ayuda. Ver [guía offline](OFFLINE_AND_SYNC_GUIDE.md).

## Errores, privacidad y salida

Si no aparece un curso, no inventes otra matrícula: puede faltar asignación, publicación, permiso o integración. Si hay error, conserva tu trabajo y pide ayuda al adulto responsable designado; el canal institucional aún no existe. No repitas muchas veces una entrega. No actives micrófono sin explicación y autorización aplicable. En equipo compartido, no continúes si ves datos ajenos. El logout real debe verificarse antes del uso escolar; cerrar una pestaña no demuestra revocación.
