# Experiencia personal

La API puede describir tareas propias pendientes, incluidos estados de revisión
solicitada. No expresa causas personales ni clasifica capacidad. No informa
resultados de evaluaciones o competencias inexistentes.

Dashboard, agenda y progreso no se conectaron a Insights en esta intervención.
Los recursos deben abrirse mediante sus módulos autorizados, no por URLs inferidas.
Las pantallas futuras deben explicar que actividad digital no equivale a aprendizaje.
