# Fuentes reales y límites

| Ámbito | Fuente autoritativa reutilizada | Estado |
|---|---|---|
| Tareas personales | Reports → Assignment/Target/Submission | Integración en código, no validada E2E |
| Revisiones docentes | Reports → asignación docente y últimas entregas | Integración en código, no validada E2E |
| Contenido institucional | Reports → catálogo publicado de Fase 41 | Integración en código, no validada E2E |
| Prácticas/juegos | Reports no acredita resultados confirmados | No disponible |
| Evaluaciones/competencias | Fase 40 parcial, sin flujo académico completo | No disponible |
| Progreso personal/aula | Fases 41/43 existentes | Sin regla Insights implementada |
| Refuerzos/calendario | Fase 42 existente | Sin regla Insights implementada |

No se consulta la base configurada durante estas pruebas. No se copian resultados
académicos ni se reconstruyen módulos anteriores. La consistencia usa definiciones
de `report_definitions.py`; filtros/población/fecha provienen del reporte generado.
La ausencia de registros devuelve información insuficiente, no falta de aprendizaje.
