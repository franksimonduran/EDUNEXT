# Métricas y denominadores

| Métrica propuesta | Numerador / denominador | Regla |
|---|---|---|
| Éxito de tarea UX | Tareas completadas / tareas propuestas válidas a participantes autorizados | No confundir renders de navegador con tareas humanas |
| Ayuda requerida | Tareas con ayuda / tareas observadas válidas | No etiqueta de capacidad; registrar condición |
| Tiempo de tarea | Tiempo observado por tarea y condiciones | Ausente = no medido, no cero ni fracaso |
| Éxito técnico de pruebas | Casos ejecutados aprobados / casos ejecutados del mismo alcance | Bloqueados/no ejecutados aparte; no ratio global engañoso |
| Confirmación Sync | Operaciones únicas confirmadas / operaciones válidas enviadas | No contar reintentos como nuevas; motor aún no operativo |
| Paquetes completos | Descargas íntegras / descargas intentadas válidas | Checksum/manifiesto, no clics |

No participantes reales: denominadores humanos inexistentes, no 0% de satisfacción/aprendizaje. Distinguir no participado, retiro, sin datos, error técnico, pendiente e incompleto. Opinión/uso no demuestra causalidad de mejora académica ni conversión AD/A/B/C.
