# Guiones UX por tarea

Usar primero adultos autorizados y datos sintéticos; con menores solo tras autorización/salvaguardas. No grabar por defecto ni sugerir que errores indican capacidad del niño.

| Rol / tarea | Consigna neutral | Observar sin dirigir / éxito esperado futuro |
|---|---|---|
| Estudiante/lección | “Busca la lección indicada y cuéntame cómo volverías al curso” | Encuentra recurso publicado, entiende navegación y alternativa textual |
| Estudiante/práctica | “Responde este ejemplo y explica qué estado ves” | Distingue feedback/puntos de nota y local de confirmado |
| Estudiante/offline | “¿Cómo sabrías si tu trabajo está enviado?” | No confunde icono de red/pendiente con recibo; hoy bloqueado para prueba real |
| Docente/entrega | “Localiza una entrega de tu aula y explica cómo publicas comentario” | Solo ámbito propio, revisión y confirmación distinguibles |
| Admin/matrícula | “Describe qué cambiaría al preparar esta propuesta” | No considera local como institucional ni elimina historia para corregir |

Registrar escenario/resultado/ayuda/barrera/tiempo solo si autorizado; no nombres o contenido privado. No ejecutar una tarea real no implementada como prueba sorpresa con menores. Ensayos humanos: no realizados.
