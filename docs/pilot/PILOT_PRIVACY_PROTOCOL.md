# Protocolo de privacidad

Inventariar finalidad/dato/fuente/personas con acceso/retención/destino/proveedor antes de recoger nada. Solo información mínima autorizada; escuela decide roles y mecanismos de derechos con asesoría. Equipo de desarrollo no obtiene consentimiento por completar plantillas.

Datos de observación preferidos: código de escenario, resultado técnico, tiempo de tarea si autorizado, ayuda requerida y barrera no identificante. No contraseñas, tokens, conversaciones completas, respuestas privadas o audio/video de sesiones por defecto.

Dispositivo compartido: validar A→B→A con datos ficticios antes; separar trabajo, cierre real y recuperación autorizada. Hoy no está certificado: no usar datos reales ni borrar pendientes para resolverlo.

Cierre: distinguir datos académicos conservables, datos temporales, logs, conversaciones y audio; política aprobada de conservación/eliminación y copias. No plazos universales inventados ni purga de expedientes. Incidentes/transferencias/encargados/proveedores requieren revisión especializada y registro seguro.
