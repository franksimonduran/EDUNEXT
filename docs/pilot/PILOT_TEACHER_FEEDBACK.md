# Instrumento docente — sin respuestas recogidas

Preguntas breves para aplicar tras autorización: ¿qué estado de tarea/borrador fue claro o confuso?, ¿pudiste localizar solo tu aula?, ¿qué paso necesitó ayuda?, ¿el feedback de ejemplo fue comprensible y pertinente?, ¿qué barrera observaste?, ¿qué mejora priorizarías y por qué?

Registrar código de sesión/tarea, tipo de observación, evidencia técnica minimizada y propuesta; no conversaciones de estudiantes, notas identificables ni archivos privados. Opinión no equivale a aprendizaje medido o aceptación de seguridad. Sin participantes, puntuaciones o testimonios fabricados.
