# Ámbito institucional

Solo implementado: condición curso sin lecciones publicadas aplicables, a partir
de `institution.courses`. Usa permisos y filtros de ese reporte, sin personas.

No implementado: patrones estudiantiles agregados, aulas sin docente, procesos
académicos pendientes o distribuciones de competencias. Antes de añadirlos se
requieren políticas Fase 43 de supresión completa/complementaria, filtros seguros
y pruebas que intenten reconstruir individuos. No hay rankings o sanciones.
