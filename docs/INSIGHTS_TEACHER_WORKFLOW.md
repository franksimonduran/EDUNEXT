# Flujo docente

Disponible en API: consultar revisiones pendientes para aula/curso asignados,
con filtros y conteos de Reports. Se muestra explicación y sugerencia opcional.

No implementado: viewed/under_consideration/dismissed/accepted_for_planning,
historial, concurrencia o formulario integrado de refuerzo. No existen botones
con una falsa confirmación de esas operaciones.

El docente debe revisar contexto en tareas antes de actuar. La creación posterior
de un refuerzo pertenece a Fase 42 y requiere confirmación y autorización propias.
Insights no crea tareas, planes ni modifica fechas/calificaciones.
