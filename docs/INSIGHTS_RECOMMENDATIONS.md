# Sugerencias e invalidación

Implementado: texto opcional para consultar tarea, revisar entregas o flujo editorial.
No hay recomendaciones de recursos concretos: no se devuelve URL ni se afirma
haber validado publicación/permisos de un material recomendado.

Los resultados no se persisten. Reconsultar recalcula las condiciones; si desaparece
el pendiente no se emite ítem. El ID cambia con valor, contexto, versión o referencia.
Esto no permite deducir un historial ni resuelve revisiones concurrentes.

Pendiente: recomendaciones persistentes, recursos autorizados, vencimiento,
deduplicación por evidencia, revalidación al actuar y revisión humana transaccional.
Una aceptación futura deberá ser solo planificación; ninguna consulta crea acciones.
